# AIT Wallet Branding & Design Tokens (`packages/branding`)

---

## 🎨 Overview

This package defines the visual identity, design tokens, color palette, and asset guidelines for the **AIT Wallet** across iOS, Android, and Web interfaces.

---

## 🟢 Color Palette

| Token Name | Hex Code | Usage |
| :--- | :--- | :--- |
| `color-primary-green` | `#0B5D34` | AIT Forest Green — Header bars, primary action buttons, active states |
| `color-primary-dark` | `#063B21` | Dark background accents, card gradients |
| `color-accent-gold` | `#D4AF37` | Gold accent — Faculty badges, high-priority highlights, borders |
| `color-surface-light` | `#F8F9FA` | Main app background, neutral surfaces |
| `color-surface-white` | `#FFFFFF` | Card surfaces, modals, elevated sheets |
| `color-text-primary` | `#1A1D20` | High-contrast body text and titles |
| `color-text-muted` | `#6C757D` | Secondary labels, timestamps, metadata |
| `color-status-success`| `#198754` | Valid credentials, approved verifications |
| `color-status-danger` | `#DC3545` | Expired / revoked credentials, verification rejections |

---

## 📱 Card UI Dimensions

- Standard Credential Card Aspect Ratio: `1.586 : 1` (Standard ID-1 / Credit card dimension).
- Corner Radius: `16px` on mobile screens.
- Micro-interactions: Haptic feedback on successful biometric authorization and QR code scan.
